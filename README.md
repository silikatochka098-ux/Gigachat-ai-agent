#  AI-помощник для анализа технических чертежей

Локальный AI-помощник, который анализирует технический чертёж и текстовую заявку, извлекает параметры изделия и задаёт уточняющие вопросы, если каких-то данных не хватает.

Основой интеллектуального анализа является **GigaChat**.

---

## 🚀 Запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/USERNAME/Gigachat-ai-agent.git
cd Gigachat-ai-agent
```

### 2. Создать виртуальное окружение

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS / Codespaces:**

```bash
python -m venv venv
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Добавить API-ключ GigaChat

Создайте файл `.env` в корне проекта:

```env
GIGACHAT_API_KEY=ВАШ_API_КЛЮЧ
```

API-ключ не хранится в репозитории.

### 5. Запустить сайт

Запустите backend:

```bash
uvicorn backend:app --host 0.0.0.0 --port 8000
```

После этого откройте локальный сайт в браузере:

```text
http://localhost:8000
```

---

## 🖥 Как пользоваться

1. Откройте сайт.
2. Загрузите технический чертёж.
3. Введите описание заявки.
4. Запустите анализ.
5. GigaChat определит параметры изделия.
6. Если каких-то данных не хватает — приложение задаст уточняющий вопрос.
7. Ответьте на вопрос, не загружая чертёж повторно.

---

## 🧠 Что делает GigaChat

GigaChat анализирует информацию из чертежа и заявки и помогает определить:

* материал;
* толщину металла;
* длину и ширину;
* количество изделий;
* отверстия и резьбы;
* технологические операции.

Если параметр невозможно определить, система не должна придумывать значение — она запрашивает его у пользователя.

## 🔮 Что можно добавить дальше

Следующий этап — подключить Excel-калькулятор и автоматически рассчитывать стоимость изделия:

```text
Чертёж + заявка
       ↓
    GigaChat
       ↓
Параметры изделия
       ↓
Excel-калькулятор
       ↓
Стоимость
       ↓
КП в Excel
```

В дальнейшем можно добавить поддержку CAD-файлов, более точный анализ чертежей, расчёт нескольких деталей и автоматическое формирование коммерческого предложения.
